# Contributing

Issues and small improvements to these public integration examples are
welcome. Keep examples provider-safe: never commit an Apify token, cookies,
private input, or credentials.

Before opening a pull request:

1. Run the examples only with a token supplied through the environment.
2. Check that sample inputs match the public Actor contract.
3. Remove run IDs, Dataset IDs, and personal data from documentation unless
   they are intentionally part of a public example.

For extraction behavior, billing, or Store-page issues, use the support
channel on the [hosted Actor page](https://apify.com/datascraperes/infojobs-jobs-scraper?fpr=edudata).
