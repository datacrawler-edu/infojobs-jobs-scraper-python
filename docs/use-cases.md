# Use cases

## Recruiting research

Search a role and city, keep the result limit bounded, and export the Dataset
to CSV for a recruiter or hiring researcher.

## Remote-work monitoring

Set `remote` to `remote`, choose a keyword such as `desarrollador`, and rerun
the same input when you need a refreshed public snapshot.

## Market and salary research

Enable `includeDetails` when the public detail response is useful. Treat
salary, benefits and application counts as fields supplied by the source and
expect them to be absent for some offers.

## Recent opportunity discovery

Set `publishedWithinDays` to `1`, `7` or `15` and `sortBy` to `date` to focus
on newer public listings.
