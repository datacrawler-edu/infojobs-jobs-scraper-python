# No-code guide

1. Open the [hosted InfoJobs Actor](https://apify.com/datascraperes/infojobs-jobs-scraper?fpr=edudata).
2. Start with `python` as the keyword and `Madrid` as the location.
3. Keep the other filters at their defaults for a broad first search.
4. Set `Maximum unique jobs` to a small value such as `10` for the first run.
5. Enable detail enrichment only when salary, skills or company fields are useful.
6. Start the Actor and open the Dataset when it finishes.
7. Review the `SUMMARY` record if the Dataset is smaller than requested.

For common searches, use the public task presets linked from the repository
README. They expose only the fields that are useful for that search intent.
